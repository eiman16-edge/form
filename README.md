A clean, responsive HTML and CSS web form featuring a custom navigation bar and styled interactive form elements. This project was built by combining manual structural layouts with AI-assisted styling.
Live Demo : 
https://github.com/eiman16-edge/form.git
Structured Layout: Semantic HTML5 hierarchy with distinct parent/child container div structures.
Custom Navigation: Clean, accessible top navigation bar.
Styled Form Controls: Custom-designed interactive checkboxes and form inputs.
Responsive Design: Built to look good on multiple screen sizes.

Collaboration & Process : 
My Contributions: Architected the HTML blueprint, defined the parent/child div relationships, structured the body, and built the navigation bar layout.
AI Assistance: Assisted with advanced CSS styling rules and refining the interactive checkbox states inside the form.
